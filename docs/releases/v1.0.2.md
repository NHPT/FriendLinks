# FriendLinks v1.0.2

FriendLinks v1.0.2 强化了主题隔离、状态一致性和展示模板扩展能力，并完成了跨主题运行验证。

## 主要更新

- 使用 Shadow DOM 隔离前台组件，主题针对 `ul`、`li`、`a`、`img` 等正文元素的样式不会覆盖友链布局。
- 修复 footer fallback 克隆节点时丢失 Shadow Root，导致部分主题下友链完全不显示的问题。
- 前后台统一显示数据库中最近一次完整检测的状态；状态不会随时间自动过期，仅在新检测结果成功写入后更新。
- 公共 `frontend.css` 与模板布局样式分离，每个模板独立维护 `style.css`。
- 取消展示模板的固定布局白名单，贡献者可以通过 `manifest.json` 与 `style.css` 新增模板，用户仍只需在后台选择模板。
- footer fallback 可以补充前台脚本，不再要求主题必须通过 header 钩子加载完整资源。

## 兼容性验证

- Typecho 1.2.1。
- PHP 7.4 与 PHP 8.2 完整领域测试和集成测试。
- MySQL/MariaDB、PostgreSQL 与 SQLite。
- 30 个固定版本的真实 Typecho 主题运行矩阵全部通过。
- 桌面端验证唯一组件宿主、Shadow Root、三列卡片和资源加载。
- 移动端验证组件可见且不存在横向内容溢出。

完整主题列表和固定提交见 [`docs/theme-compatibility.md`](https://github.com/NHPT/FriendLinks/blob/v1.0.2/docs/theme-compatibility.md)。

## 升级说明

直接使用发布包覆盖原 `FriendLinks` 插件目录即可。停用插件不会删除友链、检测历史、通知配置或其他业务数据；本版本不需要手工执行数据库迁移。

发布压缩包已包含完整 Composer 依赖，请下载 `FriendLinks-v1.0.2.zip`，不要使用 GitHub 自动生成且不包含 `vendor/` 的源码归档。
